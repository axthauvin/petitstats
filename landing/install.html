Run Petitstats
where you want.

Petitstats needs PHP 8.1 or newer with SQLite enabled.
No Node.js runtime or database server is required.

Download petitstats.tar.gz

Install in a few steps.

Web server

For shared hosting, Apache or Nginx.

  1. Download and extract the archive in your web root.
  2. Make sure your web server can write to ../petitstats-data/ (outside the web root), or set PETITSTATS_DATA_DIR.
  3. Open https://your-domain.com/dashboard/.
  4. Create the administrator account, add your site and copy its tracking snippet.
ApacheKeep the included .htaccess files and enable AllowOverride All.
NginxAdd the server rules that keep private files hidden.

Local PHP

For a quick local installation.

  1. Extract the archive in a folder of your choice.
  2. Open a terminal in that folder.
  3. Run the command below.
  4. Visit http://localhost:8080/dashboard/. 
$ php -S localhost:8080

WAMP

For a local Windows setup.

  1. Confirm PHP 8.1+ and the SQLite extension are enabled in WAMP.
  2. Extract Petitstats into C:\wamp64\www\petitstats.
  3. Start Apache from the WAMP control panel.
  4. Visit http://localhost/petitstats/dashboard/.
TipApache must be able to write to C:\wamp64\www\petitstats-data, created next to the Petitstats folder.
PHP 8.1+with the sqlite3 and pdo_sqlite extensions enabled
Write accessfor the petitstats-data/ folder, outside the web root
HTTPS accessfor the local geolocation database

Add your first website.

Once the dashboard is open, create your account, add a website, then paste its generated tracking snippet into your site’s <head>. You can also import historical events from Umami (with more providers planned soon) anytime.
