# Petitstats documentation

Petitstats is a self-hosted web analytics tool that sends the page views and events of your website to your own PHP server, without cookies by default.

This documentation is a work in progress, and contributions are welcome on [GitHub](https://github.com/axthauvin/petitstats).

## Guides

New to Petitstats? Start with the [installation guide](../README.md#quick-start), then follow these guides.

- [Tracking](tracking/README.md). Add Petitstats to your website and measure clicks.
- [Privacy and data protection](privacy/README.md). Choose how much you collect about your visitors.
- [Operations and storage](operations/README.md). Manage accounts, storage, updates and backups.
- [Importing from another analytics service](importing/README.md). Bring your past analytics with you.
- [AI assistants (MCP)](mcp/README.md). Ask Claude, ChatGPT or Cursor about your traffic.
